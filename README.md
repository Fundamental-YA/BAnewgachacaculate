# 蔚蓝档案日服卡池新机制数学建模与递推
蔚蓝档案修改的抽卡机制同时抽两个池子UP的抽数与概率计算

旧机制可以直接用简单的分段函数模拟，新机制是离散的，这里我们采用递推绘制折线的方法模拟

### 一、 状态空间定义与马尔可夫链建模
设抽卡过程为一个离散时间马尔可夫链。将所有可能的状态划分为以下三大类，其中水位 c \in [0, 199]：
 * **S_0[c]（未集齐任何UP）**：当前已进行了 c 次抽卡且未获得任何UP角色（既无A也无B）。
 * **S_{1A}[c]（已有A缺B）**：当前已获得A角色、但尚未获得B角色，且自上一次获得UP角色（或初始）以来经过了 c 次抽卡。
 * **S_{1B}[c]（已有B缺A）**：当前已获得B角色、但尚未获得A角色，且自上一次获得UP角色以来经过了 c 次抽卡。
 * **T（吸收态）**：已经集齐 \{A, B\} 双角色，成功毕业终止。
